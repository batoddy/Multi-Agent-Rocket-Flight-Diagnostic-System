Step 1 – Planned System and Goal

The planned system is RocketGuard MAS, a multi-agent rocket flight diagnostic system developed in Python. The goal of the system is to analyze rocket flight log files and generate a structured diagnostic report about the flight. The system will help users detect possible problems such as invalid log data, abnormal flight dynamics, avionics-related issues, incorrect flight state transitions, and general safety risks.

The system will support more than one input format. It will be able to read standard column-based CSV files as well as key-value style rocket logs where each row contains values such as "tick:490928;flight_state:1;alt:-0.94;press:998.17". After reading the input, the system will convert the raw data into a standard internal schema so that the diagnostic agents can analyze it consistently.

The system will follow a multi-agent approach. A CoordinatorAgent will control the complete workflow. The DataQualityAgent will detect the file format, parse the input file, map raw fields into standard fields, clean invalid values, and validate the data. The FlightDynamicsAgent will analyze altitude, velocity, acceleration, and apogee behavior. The AvionicsHealthAgent will evaluate battery, pressure, attitude, and sensor-related conditions. The StateMachineAgent will check whether the flight software state transitions are valid. The SafetyAssessmentAgent will combine all detected issues and calculate an overall risk score. Finally, the ReportAgent will generate a readable diagnostic report for the user.

The planned tools include a format detection tool, standard CSV parser, key-value log parser, schema mapping tool, data cleaning tool, validation tool, statistics tool, apogee detection tool, anomaly detection tools, battery analyzer, pressure consistency checker, state sequence validator, risk scoring tool, and report formatter. An optional LLM explanation tool may be added later, but the raw log will not be directly analyzed by the LLM. The LLM will only be used to explain already computed structured results.

The preliminary programming concepts required for this project are modular programming, object-oriented programming, multi-agent workflow design, file input/output, CSV parsing, data cleaning, schema mapping, input validation, exception handling, data transformation, risk scoring, and automated testing with pytest.
